## Verified sources (Phase 6 — reporting & export)

### SARIF 2.1.0 (VERIFIED — was UNVERIFIED in Q.5)

The SARIF specification is now at **OASIS Standard with Approved Errata 01** (28 August 2023), edited by Michael C. Fanning and Laurence J. Golding (Microsoft). Source: https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/sarif-v2.1.0-errata01-os.html

Key verified facts:
- Full canonical spec (with errata): https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/sarif-v2.1.0-errata01-os-complete.html
- Authoritative JSON schema: https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/schemas/sarif-schema-2.1.0.json (schema also mirrored in github.com/oasis-tcs/sarif-spec main branch, repo path sarif-2.1/schema/sarif-schema-2.1.0.json)
- Schema version string used in logs: "2.1.0"
- Errata #481: `runs` MUST NOT be null (schema fix). Errata #462: a `region` requires at least one of startLine/charOffset/byteOffset. Errata #468/#480: relative URIs shall not start with a leading `/`.
- Core structure: `sarifLog` { `version` (string "2.1.0", REQUIRED), `runs` (array of `run`, REQUIRED, minItems 1) }
- `run` object: `tool` { `driver` { `name` (REQUIRED), `informationUri` (optional), `version` (optional), `semanticVersion` (optional) }, `originalUriBaseIds`... }, `artifacts` (optional), `results` (array of `result`; if omitted → empty run)
- `result`: `ruleId` (string), `level` (one of "none"|"note"|"warning"|"error", enum), `message` { `text` }, `locations` [{ `physicalLocation` { `artifactLocation` { `uri` }, `region` { `startLine`, `charOffset` ... } } }], `fingerprints` (optional map), `suppressions` (optional array: { `kind`: "inReview"|"accepted", `justification` }), `properties` (optional, tool-specific extensions)
- `properties` is the designated extension point for arbitrary tool metadata (e.g., RISKX confidence, status, evidence chain, model version) — valid per spec §3.15/§3.33.
- GitHub Code Scanning consumes SARIF v2.1.0 → export has immediate practical value.

DECISION (evidence-based): SARIF export is now VERIFIED and may move out of deferred status. Implement `internal/reporting/sarif.go` exporter (findings → results with ruleId=RISKX finding ID, level mapped from severity, message.text, artifacts from assets, RISKX metadata in result.properties, run.tool.driver.name="RISKX", version="2.1.0"). Keep the exporter pure (no network) and validate output against the official schema in tests.

### JSONL / CSV (internal decision)

No external standard beyond RFC 4180 (CSV) and per-line JSON objects (JSONL). JSONL line = canonical JSON of one record; CSV uses RFC 4180 quoting. Both must emit the same metadata header lines as `--json` (version + attribution strings). Decision: serialize canonical JSON records to one-per-line; CSV flattens stable fields (id, asset, title, severity, confidence, status, validation, references) — nested evidence stays in JSONL/JSON. Documented limitation: CSV is a projection, not a lossless format.

### Report structure (spec §50 Phase 6)

Sections: executive summary / risk overview / critical exposures / affected assets / evidence / remediation. Spec requires: identity/cloud/agent/MCP sections marked as future phases. Implement `internal/reporting/summary.go` consuming []Finding + []RiskScore + []Asset from storage.

## Verified sources (Phase 7 — AWS cloud discovery)

### AWS APIs (AWS official docs)

- STS `GetCallerIdentity` (sts.amazonaws.com) returns Account, Arn, UserId — requires no IAM permission at all. Docs: https://docs.aws.amazon.com/STS/latest/APIReference/API_GetCallerIdentity.html
- Readonly enumeration approach (no-credential discovery impossible per AWS design — API access always requires creds): use env vars `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY` + `AWS_REGION` only; NO shared-credentials-file, NO instance metadata, NO profiles. Decision gated by mode: cloud discovery requires SAFE+ with explicit authorization (spec mode policy).
- EC2: `DescribeInstances` (ec2:DescribeInstances) — lists instances with public/private IPs. Docs: https://docs.aws.amazon.com/AWSEC2/latest/APIReference/API_DescribeInstances.html
- S3: `ListBuckets` (s3:ListAllMyBuckets). Docs: https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListBuckets.html
- IAM: `ListUsers`/`ListRoles` (iam:ListUsers/iam:ListRoles) — public IAM endpoint is global (iam.amazonaws.com, region us-east-1). Docs: https://docs.aws.amazon.com/IAM/latest/APIReference/API_ListUsers.html
- AWS API calls signed with SigV4; implement minimal SigV4 signing per AWS docs (https://docs.aws.amazon.com/general/latest/gr/sigv4-signed-request-examples.html) with only GET/POST query or empty bodies (no payload hash complexity for these calls). Decision: dependency-free SigV4 implementation (no AWS SDK import) per ADR-0004 dep-minimization; supported actions limited to those four (GetCallerIdentity, DescribeInstances, ListBuckets, ListUsers, ListRoles) — anything else is out of v0.2 scope.
- Asset model mapping: EC2 instance → Asset kind Service/Host with public IP exposure; S3 bucket → Service (asset value arn); IAM user/role → Identity. Provenance source: AWSCloudDiscovery (add preset in internal/evidence).
- Credentials never logged (redaction per log pkg); error if env unset → explicit error, not silent skip.

### ADR-0007 reference (already exists)

ADR-0007 selects AWS as candidate Phase 7 cloud provider. v0.2 implements the *framework* + readonly STS/EC2/S3/IAM listing — no write operations, no assume-role, no org enumeration (scope per todo Phase 7).

## AWS API verification results (checked 2026-08-12)

**STS GetCallerIdentity** (verified from docs.aws.amazon.com/STS/latest/APIReference/API_GetCallerIdentity.html): POST form-encoded, host sts.amazonaws.com, params `Action=GetCallerIdentity&Version=2011-06-15`; response XML with `<GetCallerIdentityResult><Arn>...</Arn><UserId>...</UserId><Account>...</Account></GetCallerIdentityResult>`. Explicitly stated: "No permissions are required to perform this operation."

**EC2 DescribeInstances** (docs.aws.amazon.com/AWSEC2/latest/APIReference/API_DescribeInstances.html): GET query API, params `Action=DescribeInstances&Version=2016-11-15`, endpoint `ec2.<region>.amazonaws.com` (per-region). Response: XML reservationSet/instancesSet with items (instanceId, instanceType, instanceState name, placement availabilityZone, launchTime, privateIpAddress, dnsName, publicIpAddress, publicDnsName). AWS strongly recommends pagination (MaxResults/NextToken available). DryRun parameter confirms permission without executing.

**S3 ListBuckets** (docs.aws.amazon.com/AmazonS3/latest/API/API_ListBuckets.html): GET to `s3.amazonaws.com` (global endpoint, path `/`), requires `s3:ListAllMyBuckets`. Response XML `<ListAllMyBucketsResult><Buckets><Bucket><CreationDate>...</CreationDate><Name>...</Name><BucketArn>...</BucketArn><BucketRegion>...</BucketRegion></Bucket>...` pagination via `max-buckets`/`continuation-token` query params; default page 10000.

**IAM ListUsers** (docs.aws.amazon.com/IAM/latest/APIReference/API_ListUsers.html): GET query, `https://iam.amazonaws.com/?Action=ListUsers&Version=2010-05-08` (IAM is global, version 2010-05-08). Response `<ListUsersResult><Users><member><UserId>...<Path>...<UserName>...<Arn>...<CreateDate>...</member>` + `IsTruncated`/`Marker` pagination (MaxItems default 100, max 1000).

SigV4 decision: implement minimal signing with empty payload (sha256 of ""), signed headers host;x-amz-date, canonical query string, credential scope `YYYYMMDD/region/service/aws4_request`. Services/regions/versions: sts/us-east-1/2011-06-15, ec2/{region}/2016-11-15, s3/us-east-1 (global host, region in scope us-east-1)/2006-03-01, iam/us-east-1/2010-05-08.
Creds via env only: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION (default us-east-1). Never read shared config/profiles (deterministic, auditable). Credentials redacted from logs.
Asset mapping: EC2 running instances with publicIpAddress → Asset kind Host (asset value = public IP), relationship to account; S3 buckets → Service (value = s3://{name}, provenance bucket region); IAM users/roles → Identity (value = arn). Status Observed. Provenance source AWSCloudDiscovery (add to evidence preset sources).
Command design: `riskx cloud aws` with actions whoami|instances|buckets|identities|all; requires mode safe+; no creds → explicit error (exit 2). All output via canonical JSON + provenance per asset.
